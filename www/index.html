Keep literature, evidence, methods, and manuscripts connected.

Callosum is a local-first scholarly research environment that keeps literature, evidence, methods, manuscripts, and scientific provenance connected throughout the research and writing process. A model may help draft; your own machine keeps the evidence available to inspect.

Selective, opt-in AI

Off by default, yours to swap

AI is used only for explicit, reviewable assistance: summaries, extraction candidates, triage, suggestions, and help. It is off until you configure it. Bring your own key for Gemini, OpenAI, or Anthropic, use a compatible endpoint, or keep inference on loopback. Verification remains local and is never delegated to the model.

Local-first, by construction

Your research stays local. Every door out is explicit.

Callosum binds to 127.0.0.1 and keeps PDFs, notes, indexes, checks, and citation rendering on your machine. Features that need a network connection say what they send and why.

on your computer

the explicit doors

Public metadata lookups send identifiers such as a DOI, ORCID, author, or query. Configured AI calls send the displayed task context to your chosen provider. Encrypted sync is opt-in, and feedback is sent only after an exact preview. Each door is separately controlled.

Bring your own key

Set your provider and key from Settings. They're stored in your OS keychain or a local file under ~/.callosum/ — never in the repo, never returned over the wire.

Verification never leaves

Similarity, NLI stance, and the verbatim quote search run on-device on every result. A weaker model affects draft quality — never which citations get accepted.

Accounts and sync are optional

ORCID can identify your publications, and encrypted sync can connect devices when you choose it. Neither is required for the local app; bibliographic lookups and sync never upload your PDFs, notes, or highlights as a side effect.

Free and copyleft

Licensed AGPL-3.0-or-later. Inspect it, run it, fork it. The code should never claim more certainty than the evidence can show.

The commitments

Every claim carries its evidence. The tool shows you signal, never a verdict — and always distinguishes a fact from a candidate.

i

The local substrate is the source of truth. The model only narrates it; the deterministic layer decides what holds.

ii

The human is the filter, the AI is the funnel. AI makes verification cheap; it never substitutes for it.

iii

Inspectability over authority. No opaque composite scores; coordinates are labeled exact, region, or null — never dressed up.

iv

Local-first and provider-swappable. It runs on your machine and answers to no single vendor; silence is never a certificate.

three hard lines

No paywall circumvention — open-access only. No reaching into another tool's protected store — imports use supported exports and interfaces. No accusation of individuals — integrity signals point you to inspect evidence, never to judge a person. These have no “aligned alternative.”

Build from source

Clone it, build the frontend, open a browser.

You'll need a couple of standard tools. Some local analysis features download models on first use, then run offline. The SQLite database auto-migrates on startup. The source tree also includes a read-only MCP server and a terminal client for working with the same local API.

→ Python 3.11+ — backend & verification
→ Node.js — frontend build & citation engine
→ Windows, macOS, or Linux
bash — macOS / Linux
# 1 · clone
$ git clone https://github.com/cliffworkman/callosum.git
$ cd callosum

# 2 · python + js dependencies
$ uv sync
$ npm install

# 3 · build the single-file frontend
$ uv run python tools/build_frontend.py

# 4 · run it, then open 127.0.0.1:8080
$ uv run uvicorn app.backend.api.app:app --port 8080

Where it honestly stands

Pre-1.0 and single-user-focused. It's used daily by its author and backed by 2,098 tests, but the interface is still moving, installers are unsigned, and the local-first architecture is not a hardened multi-tenant hosted service. Expect rough edges. Stating that plainly is itself the point: the site and the code should not claim more certainty than the evidence shows.

Callosum

After the corpus callosum — the band of fibers that carries signals between the brain's two hemispheres, so neither is trusted blindly. Here it bridges a model that drafts and a substrate that verifies.
