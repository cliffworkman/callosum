One enclosed ecosystem

Find it, read it, check its statistics, synthesize it, cite it — without leaving the app.

Most of us stitch this together from a search engine, a PDF reader, a stats checker, a reference manager, and a word-processor plugin. Callosum is the whole arc in one local-first place — and after import, none of it needs the internet.

Read & annotate

An in-browser reader

Verified synthesis · the core

Citation-grounded summaries

Every generated sentence is re-checked against the source and labeled verified, contrasted, flagged, or contradicted — with its quote, page, and confidence. Coordinates are marked exact, region, or null, and never shown as more precise than they are.

Selective, opt-in AI

Off by default, yours to swap

AI is used for generation only — summaries, axis-term suggestions, and a help assistant whose own answers are citation-grounded too — and it's off until you turn it on. Bring your own key for Gemini, OpenAI, or Anthropic, or point it at any OpenAI/Anthropic-compatible endpoint — Ollama, DeepSeek, OpenRouter, and the like; a local, loopback provider runs with zero egress. The roster is yours to edit. Verification is always local, never delegated to the model.

Local-first, by construction

Everything stays on your machine — until you decide otherwise.

Callosum binds to 127.0.0.1. After import it works fully offline. The only data that can ever leave is AI generation you switch on, sentence by sentence.

the one door

When you opt in to AI summary generation, the relevant text — and nothing else — is sent to the provider you chose. Set CALLOSUM_ALLOW_DATA_EGRESS=1 to open it. It's shut by default.

Bring your own key

Set your provider and key from Settings. They're stored in your OS keychain or a local file under ~/.callosum/ — never in the repo, never returned over the wire.

Verification never leaves

Similarity, NLI stance, and the verbatim quote search run on-device on every result. A weaker model affects draft quality — never which citations get accepted.

Optional ORCID, identity-only

Signing in verifies who you are and pre-fills My Publications. It sends no library text, PDFs, or notes anywhere. The app works fully offline with no account.

Free and copyleft

The commitments

Every claim carries its evidence. The tool shows you signal, never a verdict — and always distinguishes a fact from a candidate.

i

The local substrate is the source of truth. The model only narrates it; the deterministic layer decides what holds.

ii

The human is the filter, the AI is the funnel. AI makes verification cheap; it never substitutes for it.

iii

Inspectability over authority. No opaque composite scores; coordinates are labeled exact, region, or null — never dressed up.

iv

Local-first and provider-swappable. It runs on your machine and answers to no single vendor; silence is never a certificate.

two hard lines

No paywall circumvention — open-access only. No accusation of individuals — the open-science signals point you to look, never to judge. These have no “aligned alternative”; they are lines the tool does not cross.

Quickstart

Clone it, build the frontend, open a browser.

You'll need a couple of standard tools. First run pulls a few hundred MB of local models from Hugging Face — once — then it works offline. The SQLite database auto-migrates on startup.

→ Python 3.11+ — backend & verification
→ Node.js — frontend build & citation engine
→ Windows, macOS, or Linux
bash — macOS / Linux
# 1 · clone + a virtual environment
$ git clone https://github.com/cliffworkman/callosum.git
$ cd callosum
$ python -m venv .venv && source .venv/bin/activate

# 2 · python + js dependencies
$ pip install -r requirements.txt
$ npm install

# 3 · build the single-file frontend
$ python tools/build_frontend.py

# 4 · run it, then open 127.0.0.1:8080
$ uvicorn app.backend.api.app:app --port 8080

Where it honestly stands

Pre-1.0 and single-user-focused. It's used daily by its author and backed by a large test suite, but there's no auth for hosted deployment, the surface is still moving, and you should expect rough edges. Stating that plainly is itself the point — the README and the code shouldn't claim more certainty than the evidence shows.

Callosum

After the corpus callosum — the band of fibers that carries signals between the brain's two hemispheres, so neither is trusted blindly. Here it bridges a model that drafts and a substrate that verifies.
