# GROBID

Planned - not yet implemented.

Intended role: GROBID will provide structured scholarly PDF parsing for headers, sections, references, citation structures, and possibly coordinates where PyMuPDF text extraction is not enough.

Future tracks depending on it:

- `opus4.8_future-tracks.md` Track C for highlight-to-suggest and highlight-to-evaluate workflows that need section/reference structure.
- `opus4.8_future-tracks_theorymethods.md` and `opus4.8_future-tracks_theorymethodsextension.md` where richer paper structure may improve inspectable THEORY/METHODS modules.
