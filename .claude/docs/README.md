# Docs Index

`.claude/docs/` is the dev/internal planning and reference suite for Callosum. It is not shipped application content.

## Current Live Docs

- `INCREMENT-BACKLOG.md`: near-term increment queue and current planning source.
- `future-tracks/`: longer-horizon design-toward prompts.
- `future-tracks/README.md`: index for the future-track documents.
- `future-tracks-import/`: watched inbox for future-track material before it is folded into the plan.
- `increment-notes/`: per-increment diary and implementation notes.
- `architecture.md`: implemented architecture snapshot.
- `data-contracts.md`: implemented schema and payload contracts.
- `product-scope.md`: current shipped scope and explicit longer-horizon exclusions.
- `ux-scope.md`: current UI surfaces and evidence-display commitments.
- `risk-register.md`: current MVP risks and deployment/security notes.
- `glossary.md`: shared vocabulary for the implemented system and future-track terms.
- `build-log.md`: historical build log, retained as a factual implementation record.

## One Level Up

These project-level references live in `.claude/`, not this directory:

- `CLAUDE.md`: authoritative session briefing and current-state source.
- `PRINCIPLES.md`: project charter and alignment gate.
- `APPROACH-AVOIDANCE.md`: deeper value substrate and veto boundaries.
- `DESIGN.md`: design dictionary and CSS/UI rules.

## Archived

`roadmap.md` and `backlog-future-tracks.md` are archived in `.claude/deprecated/`. Do not treat them as live planning docs; use `INCREMENT-BACKLOG.md` and `future-tracks/` instead.
