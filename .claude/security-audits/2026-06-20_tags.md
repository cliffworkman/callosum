# Security Audit — Tags (per-paper labels + filter) (increment 71)

**Date:** 2026-06-20
**Trigger:** Three new API endpoints (`GET /tags`, `POST /papers/{id}/tags`, `DELETE /papers/{id}/tags/{tag_id}`)
+ a net-new feature (new repo module + detail field + frontend). No new schema/migration (the `tags`/
`paper_tags` tables already exist).

## What changed
Lightweight free-form tags on papers: view/add/remove on the Details pane, click a tag to filter the library
(`GET /papers?tag_id=`). Surfaces tags the Zotero importer already populates. New `persistence/tags_repo.py`
holds the data access; `routers/tags.py` the endpoints.

## Threat review
- **Local, no egress.** All endpoints read/write local rows only — no external call, no file write.
- **Non-destructive to papers.** Tags manage `paper_tags` links + the `tags` row; they never touch papers.
  Removing a tag's last link **prunes** the orphan tag (keeps the tag list meaningful) — affects only the
  tag, never a paper.
- **SQL injection (rule #3):** every query in `tags_repo.py` + the `list_papers(tag_id=)` filter is
  bound-param SQLAlchemy Core (`select/insert/delete` with `==`/`.in_(select(...))`); the tag name is a
  **bound value**, never interpolated.
- **Input validation (rule #4):** `AddTagRequest.name` is a Pydantic `str` `min_length=1, max_length=100`;
  the handler also rejects whitespace-only (`422`). `add_tag_to_paper` trims + caps to 100 chars. `tag_id`
  / `paper_id` are int path params. Unknown paper → 404; unlinked tag delete → 404.
- **Output encoding / XSS:** the tag name is stored + returned as **plain text** and rendered by React as a
  text node (no `dangerouslySetInnerHTML`), so a tag like `<script>` is shown literally, not executed.
- **Resource:** `GET /tags` is bounded by the tag count; add/remove touch one row. The library `tag_id`
  filter is a single bound `IN` subquery.
- **API surface:** one new GET (`/tags`, added to the read allowlist) + two mutations (`/papers/{id}/tags`
  POST, `/papers/{id}/tags/{tag_id}` DELETE, added to the mutation allowlist) in `tests/test_health.py`.
  The new paths don't collide with existing routes (no prior `/papers/{paper_id}/tags*`; `/tags` is fresh).
  CORS unchanged.
- **Migration / deps:** none.

## Negative-path checks (results)
- Blank/whitespace name → **422**; unknown paper → **404** (`test_tag_endpoints_*`). **PASS.**
- Adding the same name twice → idempotent (one tag, one link); two papers reuse the same global tag
  (`test_add_get_dedupe_and_idempotent`). **PASS.**
- Removing a tag's last link prunes the orphan; removing a non-linked tag → **404**
  (`test_remove_unlinks_and_prunes_orphan`, endpoint test). **PASS.**
- `GET /papers?tag_id=` narrows to the tagged paper and **excludes trashed** ones; composes with `q`
  (`test_list_papers_tag_filter_composes`). **PASS.**
- **Live E2E** (`.local/tags_e2e/`): add a tag → click it → "Filtered to tag method" + the library narrows →
  clear → remove the chip. **0 console errors.** **PASS.**

Full suite: **248 passed** (+4). No new dependency; no migration; no egress.

**Security Audit: PASS.**
