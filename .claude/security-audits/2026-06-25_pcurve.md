# Security audit — p-curve (collection-level evidential-value check) (inc 126)

**Date:** 2026-06-25 · **Feature:** a new `POST/GET /methods/pcurve/run` async job that runs a p-curve over a
user-selected set of papers (reusing the statcheck extractor), + a frontend modal. Backend + frontend.

**Audit-gate triggers:** new API endpoint (#1); net-new feature spanning 3+ files (#5). NOT a new external
service.

## Threat review

- **Data egress (invariant #3):** none. p-curve is **deterministic, local, no-LLM**: it reads the papers'
  already-extracted chunk text and recomputes p-values with scipy. No network call, no Gemini. The headed run
  made **0 requests** to any genai host. (The credit "add to library" rides the inc-93 `/library/import`, which is
  local — no egress — and already audited.)
- **Input validation (rule #4):** `PcurveRunRequest.paper_ids` is de-duplicated, capped at `MAX_PCURVE_PAPERS =
  1000`, and rejected with **422** when empty. The job intersects the ids with `list_live_paper_ids` (trashed
  papers excluded); unknown ids are simply skipped. statcheck's own `MAX_RESULTS = 500` per paper bounds the
  per-paper work.
- **SQL (rule #3):** all reads go through existing bound-parameter repository functions
  (`get_chunks_for_paper`, `list_live_paper_ids`). No string interpolation, no new query surface.
- **No persistence / no migration:** the result is ephemeral (returned by the job, never stored) — no new table,
  no write path beyond the (audited) credit-add import.
- **Untrusted output / DoS:** the math is bounded (k significant tests ≤ the per-paper cap × selection cap);
  `norm.ppf` inputs are clamped to `(1e-12, 1−1e-12)`; division guarded (k>0 checked). No user text reaches a
  shell/eval/SQL.
- **Frontend output encoding:** the modal renders all values as React text/SVG (`{t.raw}`, numeric stats) —
  escaped, no `dangerouslySetInnerHTML`. The bundled credit CSL-JSON is a hardcoded literal (not user input).
- **Credit-add:** posts a **hardcoded** CSL-JSON (Simonsohn et al. 2014) to `/library/import` (inc 93; parses →
  dedups → creates; idempotent). No user-controlled path; re-adding is safe.

## Negative-path checks (run)

- Empty `paper_ids` → **422** (`test_pcurve_endpoint_over_a_selection`). ✔
- Unknown job id → **404**. ✔
- A selection with no significant inline NHST tests → honest empty result + note (no crash). ✔ (unit + the note)
- Live, no-egress headed run over 12 papers → curve + stats, **0 genai requests, 0 console/page errors**. ✔

## Principles alignment (rule #9)

Aligned (PRINCIPLES Example 3 lineage): **collection-level only**, present-the-curve-not-a-verdict, **never
per-paper**, **never labels a paper or author "p-hacked"** (the A-A veto-level no-accusation boundary), coverage
stated (inline-NHST only; can't pick the focal test; small-k unreliable; rounds-to-0 conservatively dropped), the
included tests are inspectable (each opens its page at region precision), no composite score / no rank. Declined
easy path: a per-paper "evidential value / p-hacking" badge or rank.

**Security Audit: PASS**
