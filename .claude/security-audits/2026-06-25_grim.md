# Security audit — GRIM + GRIMMER calculator (inc 127)

**Date:** 2026-06-25 · **Feature:** a sync `POST /methods/grim` endpoint computing GRIM/GRIMMER consistency on
user-entered values, + a frontend METHODS section. Backend + frontend.

**Audit-gate triggers:** new API endpoint (#1); net-new feature spanning 3+ files (#5). NOT a new external service.

## Threat review

- **Data egress (invariant #3):** none. GRIM/GRIMMER are **deterministic, local, no-LLM** arithmetic on the
  values the user types — no paper text, no network, no Gemini. The headed run made **0** genai-host requests.
  (The credit "add to library" rides the inc-93 `/library/import`, local + already audited.)
- **Input validation (rule #4):** `grim_test`/`grimmer_test` reject `n <= 0`, `items <= 0`, and `n > MAX_N`
  (1e6) / `items > MAX_ITEMS` (1e3) with `ValueError`; non-numeric mean/SD raise on `float(...)`. The endpoint
  catches `(ValueError, ArithmeticError)` → **422** (never a 500). Verified: `n=0` → 422 (endpoint test).
- **DoS / bounded work:** GRIM is O(1) (a few candidate totals). GRIMMER's only loop is over the integer
  sum-of-squares interval `[ceil(ss_lo), floor(ss_hi)]`, whose width is bounded by the SD rounding half-ulp ×
  (n−1) — small for realistic inputs and hard-bounded by the n/items caps. No unbounded enumeration.
- **SQL / DB:** none — the endpoint touches no database. No new query surface.
- **Output encoding (frontend):** all values render as React text (`{d.grim.note}`, the nearest list, pills) —
  escaped, no `dangerouslySetInnerHTML`. The bundled credit CSL-JSON is a hardcoded literal (not user input).
- **No persistence / no migration.**

## Negative-path checks (run)

- `n = 0` → **422** (`test_grim_endpoint`). ✔
- Non-numeric mean/SD → raises → **422** (the endpoint's `except`). ✔
- GRIM-inconsistent mean → GRIMMER short-circuits to inconsistent (no crash). ✔ (`test_grimmer_requires_grim_consistent_mean`)
- items≠1 with SD → GRIMMER returns `supported=False` (honest), GRIM still computed. ✔
- Headed, no-egress: impossible + consistent cases, add-to-library — **0 genai requests, 0 console/page errors**. ✔

## Principles alignment (rule #9)

Aligned (PRINCIPLES Example 3 lineage): **assisted, per-value, user-driven** → inherently non-accusatory (the
user picks the value; the tool never scans, ranks, or labels a paper/author — the A-A veto-level no-accusation
boundary). Signal-not-verdict ("a prompt to look"); the nearest-possible values + granularity make an "impossible"
result inspectable (#8); integer-scale + no-power caveats (#6, silence ≠ certificate); no composite score (#7).
Declined easy path: an auto-scanner that flags means with guessed Ns.

**Security Audit: PASS**
