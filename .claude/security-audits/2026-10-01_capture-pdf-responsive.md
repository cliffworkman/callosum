# Capture response classification and scheduling

Security Audit: PASS for the reviewed local changes and automated boundaries; packaged browser acceptance remains pending.

Generic fallback requires identified HTML; unknown/inaccessible content is never canonical metadata. Existing app-owned model registry and source inputs remain unchanged.

Capture workers are awaited behind an app-scoped async lock; idempotency is rechecked inside it. Upload paths are server-minted and removed after worker completion or failure.
